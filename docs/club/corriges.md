# Corrigés et grille de correction (réservé aux enseignants)

Ne jamais distribuer ce document aux élèves. Corriger sans connaître le groupe de l'élève : ne regarder que son code.

## Règles de correction

- Chaque item vaut tout ou rien. Total sur 20.
- Réponse numérique : valable si la valeur est exacte, sous n'importe quelle écriture équivalente (−5/2, −2,5, −2.5). Le signe doit être correct.
- « Je ne sais pas » ou case vide : 0 point, code VIDE. Une réponse fausse qui ne figure pas dans la liste : code AUTRE.
- Pour chaque item faux, écrire le code d'erreur dans la feuille d'analyse (colonne de l'item). Un item juste n'a pas de code.

## Ordre de passation (carré latin)

- Ordre 0 (code ÷ 3, reste 0) : V1, V2, V3
- Ordre 1 (reste 1) : V2, V3, V1
- Ordre 2 (reste 2) : V3, V1, V2

Les trois versions sont données dans cet ordre à l'avant-test, à l'après-test immédiat et au test différé, pour chaque matière. Ainsi aucune version n'est toujours placée à la même occasion. Le code élève est un numéro ; le reste de sa division par 3 donne l'ordre.

## Codes d'erreur

| Code | Sens |
|---|---|
| SIGNE | mauvais signe du résultat |
| OPERATION | opération fausse (soustraction, addition) |
| INVERSION | numérateur et dénominateur échangés |
| PRODUIT | produit au lieu d'un quotient |
| ZERO / SAVOIR / EGAL | réponse « nul », « on ne peut pas savoir », « = » |
| DECALAGE / NUMERATEUR | position sur la droite : entiers voisins décalés, ou numérateur utilisé comme position |
| COMPARAISON | négatifs comparés comme des positifs (le plus grand en valeur absolue jugé le plus grand) |
| POURCENT / DECIMAL | pourcentage : division par 100 oubliée, ou faite deux fois |
| SOUSTRAIT / ADDITION | pourcentage soustrait ou ajouté au lieu d'être appliqué |
| MULTIPLIE | pourcentage appliqué au mauvais volume |
| O2 / N2 / CO2 | gaz confondu |
| INVERSE | sens de variation inversé (pression, masse) |
| NOCHANGE | « ne change pas » pour la pression |
| RETRECISSENT / DISPARAIT / NOMBRE | idées fausses sur les particules |
| AIRSANSMASSE | l'air est jugé sans masse |
| AUTRE / VIDE | réponse hors liste / pas de réponse |
