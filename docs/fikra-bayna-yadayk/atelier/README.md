# الورشة · Atelier

الحالة: نموذج أولي v0 للمراجعة. التاريخ: 24 نوفمبر 2026. خارج الإنتاج.

## الفكرة

توليد درس «الفكرة بين يديك» من المنصة نفسها، دون الرجوع إلى Claude في كل مرة.
الطريقة مختلطة:

- الذكاء الاصطناعي يقترح بطاقة الدرس، أي النصوص والأخطاء الشائعة والأسئلة والتمارين.
- التجربة الحية تُختار من مكتبة جاهزة، ولا تُكتب لها شيفرة جديدة.
- المحرك يتحقق آليا، والأستاذ يراجع قبل النشر.

## المسار

1. الأستاذ يملأ البطاقة في `atelier.html`، أو يطلب اقتراحا من الذكاء الاصطناعي.
2. البطاقة ملف JSON فيه نصوص وعمليات حسابية فقط، بلا HTML ولا JavaScript.
3. `fikra-spec.js` يحوّل البطاقة إلى درس يفهمه المحرك. كل نص يُعقَّم، وكل عملية تمر عبر محلّل آمن بلا `eval`.
4. المحرك نفسه يتحقق: جواب صحيح واحد لكل سؤال، ورموز الأخطاء موجودة، و300 تمرين لكل مستوى بلا فخ يساوي الجواب.
5. الأستاذ يراجع بورقة المراجعة ثم يقرر النشر.

## الملفات

| الملف | الدور |
| --- | --- |
| `fikra-spec.js` | المحوّل: محلل العمليات الآمن، ومكتبة التجارب، والمهام، والتمارين |
| `specs/*.json` | بطاقات الأمثلة |
| `build_spec.py` | يبني درسا من بطاقة: `python3 build_spec.py specs/X.json ../lecons/X.html TEMPLATE` |
| `atelier-src.html` و `build_atelier.py` | مصدر الورشة وأداة تجميعها في ملف واحد `atelier.html` |
| `prompt-ia.md` | تعليمات خدمة الاقتراح على الخادم |

## مكتبة التجارب v0

- `curseurs`: منزلقات، وقيم محسوبة، وأشرطة، ودفتر تجارب.
- `graphe`: منحنى يُرسم بقيم المنزلقات، ونقطة متحركة، ومنحنيات سابقة بخط متقطع.

نوعا المهام: `valeurs`، أي رؤية قيم معينة لمنزلق، ويمكن تقييدها بشرط. و`condition`، أي تحقق شرط حسابي.

المرشحة للإضافة: أنابيب وصفيحة كاشف لـ SVT، وشكل هندسي بنقط متحركة، ودارة كهربائية بسيطة، وميزان. درسا الطاقة الحركية والأميلاز ما زالا مكتوبين بشيفرة خاصة، ويصيران بطاقات حين توجد تجاربهما في المكتبة.

## الدرسان المبنيان من بطاقة

نجحا في اختبار المسار نفسه. لم يراجعهما أستاذ.

## ما لم يُنجز بعد

- خدمة الاقتراح على الخادم. الزر موجود، و`AI_ENDPOINT` فارغ.
- الحسابات والصلاحيات وحفظ البطاقات على المنصة.
- خانات العربية في الاستمارة تعرض الرموز اللاتينية بترتيب مربك أحيانا. العرض في الدرس نفسه سليم.
