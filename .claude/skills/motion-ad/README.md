# Motion Design

Make motion graphics with Claude. Everything is code, rendered on your machine. No AI video model, nothing paid, nothing to install in Claude.

## Start
1. Add this folder to Claude (add folder).
2. Type: **start motion design**

That's it. Claude reads the skill from the folder, checks what your computer needs and walks you through the rest, one step at a time.

## What you'll need on your computer
Node 18+ · Python 3 (Pillow, numpy, scipy, opencv-python) · ffmpeg · Google Chrome
The first step checks all of this for you and tells you what to install.

## How a project runs
Each ad gets its own folder in here, e.g. `Spotify/`, with `assets/`, `sounds/` and `out/`.
Brief → Assets → Ending → Storyboard → Build → Render → Sound. You approve each step.
